# Design principles

1. **Process over prose.** A skill is a workflow with named tool calls, not an article about a topic.
2. **Preliminary, never final.** Output says "appears to", "usually", "to verify". Decisions belong to authorities and licensed professionals.
3. **Every fact carries provenance.** Source, date fetched or reviewed, and a link the user can open.
4. **Freshness is checked, not assumed.** Each skill declares `review_threshold_days` and checks knowledge age at runtime.
5. **Humans do the irreversible parts.** Submitting, signing, paying, logging in, OTPs and declarations stay with the user.
6. **Minimum personal data.** Ranges and counts instead of documents and numbers.
7. **Graceful degradation.** When a server is down, say what could not be checked and continue in a reduced mode.
8. **Hand-off built in.** Each output ends with what a licensed professional must confirm and a brief the user can send them.
9. **No implied affiliation.** No official logos, emblems or language suggesting endorsement.
